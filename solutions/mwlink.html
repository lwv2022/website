Developer Integration

RESTful API Suite

mwLink provides comprehensive REST APIs based on the OpenAPI standard, enabling integration with BMS, custom dashboards, and third-party applications.

🔐 Authentication API

JWT-based authentication for secure site access. Get and refresh tokens programmatically.

🏗️ Project API

Access site structure from areas to zones to devices. Retrieve scenario parameters and configurations.

💡 Device Control API

Get and set lighting states for any zone. On/off control and 0-100% dimming levels.

📡 Gateway Status API

Monitor gateway connectivity for each area. Know when you can rely on status and control.

⚠️ Faults API

Device fault information including lamp failures, driver issues, and end-of-life warnings.

👥 Occupancy API

Historical occupancy data in 15-minute intervals. Up to 24 months of retention.

⚡ Energy API

Zone and device-level energy consumption. 15-minute intervals with completeness tracking.

📚 OpenAPI Docs

Full Swagger documentation at api.mwlink.us/docs. Postman collections available.
